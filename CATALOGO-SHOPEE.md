# Catálogo atualizado a partir da Shopee

Este projeto foi preenchido com os produtos dos arquivos de exportação fornecidos:
- informações básicas (títulos e descrições)
- mídia (fotos)
- informações de vendas (preços)

As fotos são referenciadas pelas URLs da Shopee para manter o projeto leve e evitar armazenar centenas de imagens no deploy.
